# 语言策略

站点界面以简体中文为主。导航、操作按钮、状态、错误提示、页面标题和默认 SEO 文案使用简体中文；`<html lang="zh-CN">` 与 Open Graph `zh_CN` 与此一致。MIDI、Slug、SHA-256、UTC、API 等标准名词和环境变量名保持原写法。`/map` 等既有 URL 是稳定地址，不因界面标签变更而改动。

档案内容保留史料原语言。作品标题、人物姓名与历史昵称、来源网站名称、原始说明和引用网址按可核实的原文记录；整理者写的新简介、来源备注、寻回经过和证据说明优先使用简体中文，并在需要时附上原文。不要为追求界面一致而自动翻译、音译或覆盖原始内容，也不要凭不完整日期补出日期。

公开详情的标题和描述来自档案记录，可能不是中文；页面界面的语言标记只描述界面默认语言，不宣称每条史料都已翻译。当前不提供语言切换或平行翻译字段。未来若加入多语言内容，应先为各条内容定义语言标记、译文与来源的关系，并为每个语言版本配置独立的 canonical 与 hreflang；不能仅复制页面并改变语言标签。
