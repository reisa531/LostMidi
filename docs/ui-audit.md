# 页面与流程审查记录

以下记录来自代码路由、数据流和空/错误态检查；桌面及手机浏览器尚待最终执行环境确认。

| 页面 / 流程 | 检查与发现 | 处理 / 验证 |
| --- | --- | --- |
| 首页、MIDI 列表、图谱、寻回 | 复核页面入口、分页组件和公开权限字段。 | 复用目录查询；保留已有空态和服务错误态；日期展示改为日期优先。 |
| MIDI 详情 | 文件权限文案原先容易被理解为所有文件均可下载；不可下载状态缺少申请入口；简介/来源/寻回长文为纯文本。 | 按文件下载许可区分提示，添加联系链接；接入安全 Markdown；无文件显示“尚未收录文件”。 |
| 人物列表、详情 | 列表有作品分组但无精确搜索入口；详情仅展示昵称和简介，无资料侧栏、目录、邻接导航与更新时间。 | 新增内部 ID 人物筛选、结构化资料区块、简介目录、前后人物、摘要与更新时间。 |
| 搜索 | 原搜索只处理关键词，空关键词筛选人物不可用。 | 支持人物 ID 和可选关键词交集；分页保留条件；不退回全库结果。 |
| 关于、更新日志、404 | 关于页旧文案曾暗示无下载；核对页脚入口、日志版本校验。 | 更新关于/联系入口与权限文案；日志版本与包版本按发布脚本检查。 |
| 后台登录/退出、安装、邀请接受 | 检查路由组件、action 的 origin/session 校验和状态提示。 | 沿用现有身份校验、邀请令牌与输入保留；未发现本批字段触及安装/邀请逻辑。 |
| 后台总览、用户、审核、回收站 | 检查角色门禁、普通管理员审核说明、review action 和恢复/删除入口。 | 新人物 profile 与摘要仍走现有审核 payload；revision 保持原值检查。 |
| 人物新增/编辑 | 表单原先只接受简介和 aliases。 | 添加摘要及 profile 表单；兼容未提供新字段的旧 API 客户端；字段约束由 service 校验。 |
| MIDI 列表/新增/编辑 | 列表原先无关键词/状态筛选且标题不可点；编辑子页导航不一致。 | 使用目录接口的分页/搜索/状态/排序；标题链接编辑；共用四区导航；估算日期支持日历录入。 |
| MIDI 署名、来源与寻回、文件 | 核对请求审核、文件重试及版本冲突；寻回编辑曾加载整页人物选项。 | 署名继续关联人物；寻回人转成文本快照；保留上传和 revision 机制。 |
| 窄屏、键盘、SEO | 检查表单 min-width、可见焦点、外链 target 和 metadata。 | 新内容使用可换行布局、语义导航、标题/摘要/OG/Twitter；需实机截图验收。 |
