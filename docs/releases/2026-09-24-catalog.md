# 前后台改版与同页建档上传：本地验收记录

日期：2026-09-24。本文记录本地实现与测试，不表示生产已发布。

## 完成范围

- 前台：首页总览、MIDI、作者、寻回进度、Map；关于项目移至页脚。真实统计、状态筛选、排序、分页、作者/来源分组、空态和非法参数提示。
- 后台：精简导航与工作台，删除管理功能占位页以及服务连接/工作模式卡片。
- 新建档案：可选单个 MIDI 文件、公开分发确认、资料与文件原子保存、幂等回执、失败保留输入、响应丢失后安全重试。纯资料建档在导入启用和禁用时均可用。
- 收尾修复：导入开关经管理员会话传到新建页；未选文件时移除空文件控件占位值；修复 Windows max 宏冲突及目录统计测试的 PostgreSQL 参数类型推断冲突。

- 前端 lint、类型检查、Next.js 生产构建（webpack）通过。
- HTTP：组合建档、校验失败、幂等重放、目录查询、导入禁用、匿名下载和逐字节核对通过；空、截断、损坏、超长和缺失对象均被拒绝。
